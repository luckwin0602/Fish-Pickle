# 🚀 QUICK START GUIDE - Golden Fish Pickles Website

## ⚡ Get Started in 30 Seconds

### Option 1: Direct Open (Easiest)
1. Open the folder: `c:\Users\DELL\Desktop\fish project`
2. Right-click on `index.html`
3. Select "Open with" → Choose your browser
4. **Done!** Website is now live in your browser

### Option 2: VS Code (Recommended)
1. Open VS Code
2. Go to: File → Open Folder
3. Select: `c:\Users\DELL\Desktop\fish project`
4. Right-click on `index.html` → "Open with Live Server"
5. Website opens with live reload enabled

### Option 3: Local Server
Open PowerShell in the project folder and run:
```powershell
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 🎨 Customization Quick Tips

### Change Company Name
Open `index.html`, search for "Golden Fish Pickles" and replace with your company name.

### Change Colors
Edit `styles.css` (lines 8-12):
```css
:root {
    --primary-color: #FF6B35;      /* Main color */
    --secondary-color: #004E89;    /* Accent */
    --accent-color: #F7931E;       /* Highlight */
}
```

### Add More Products
Duplicate a product card in `index.html` (around line 110) and update:
- Product name
- Price (₹)
- Weight
- Emoji icon

### Update Location Info
Edit the location section in `index.html` (around line 185):
- Address
- Phone number
- Email
- Business hours

## 🔧 Troubleshooting

**Website looks broken?**
- Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser
- Ensure all files are in the same folder

**Animations not working?**
- Use a modern browser (Chrome, Firefox, Safari, Edge)
- Check browser console for errors (F12)

**Buttons not responding?**
- JavaScript might be disabled - enable it in browser settings
- Check console for errors
